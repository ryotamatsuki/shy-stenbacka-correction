# RIO author metadata and declaration inputs required before Stage-14 full PASS

Status: **AUTHOR INPUT REQUIRED**  
Date: **2026-09-20**

The public Review of Industrial Organization instructions require a title page with author identity/affiliation/corresponding-author information and require disclosure information. The repository must not infer or invent these facts.

Before Stage 14 can reach full `SUBMISSION QA PASS`, supply and verify:

1. exact author name(s) and order;
2. primary affiliation(s): institution, department if used, city, state/region, country;
3. corresponding author designation and active email;
4. ORCID(s), if available;
5. acknowledgments, if any;
6. funding status and exact funder/grant wording, or a truthful no-funding statement;
7. competing financial and non-financial interests, or a truthful no-interest statement;
8. author-contribution wording / CRediT roles;
9. confirmation that all authors approve the manuscript and submission;
10. confirmation that this manuscript is not simultaneously under consideration elsewhere and has not already been published in a conflicting form;
11. any prior preprint, thesis, conference-paper, or unpublished-material relationship that needs transparency;
12. any author-specific AI-declaration detail that should be added beyond the current manuscript statement.

Current known declarations already in the manuscript:

- Data availability — theoretical study; no empirical dataset generated/analyzed.
- Code availability — public repository identified.
- Use of generative AI — substantive research-assistance use disclosed with human accountability.

These known declarations do not substitute for author-specific funding, competing-interest, authorship, affiliation, or prior-publication facts.
