# Verification Code

Code is used as an independent check of the analytical argument.

Permitted roles include:

- symbolic simplification and factorization;
- inequality verification;
- exhaustive parameter-region checks where exact arithmetic is available;
- numerical counterexample search;
- plots used only as diagnostics.

Code must not substitute for proof of an equilibrium claim.

When scripts are added, record:

- software and version;
- package versions;
- exact parameter assumptions;
- deterministic seeds where relevant;
- expected output;
- which manuscript/audit claim the script checks.
