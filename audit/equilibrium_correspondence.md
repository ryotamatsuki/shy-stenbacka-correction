## Classification vocabulary

Use only:

- **NASH** — all unilateral deviations checked and none profitable.
- **NOT NASH** — at least one explicit profitable deviation.
- **KNIFE EDGE** — equilibrium only under equality conditions.
- **INFEASIBLE** — violates a model constraint.
- **UNRESOLVED** — proof incomplete.

## Completeness gate

This stage passes only if the union of classified parameter regions covers the admissible parameter space, modulo explicitly identified measure-zero/knife-edge cases.
