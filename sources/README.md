## Rules

- Prefer publisher-final bibliographic metadata for identity checks.
- Keep private PDFs under `sources/private/` or `sources/pdfs/`; both are gitignored.
- If an open-access copy is used, record why it is textually identical to the published version or note all differences.
- Every equation transcribed into the audit should be traceable to page/equation number.
